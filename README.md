# OCTC Blackboard Start Here

Shared student resources for Start Here modules in OCTC Blackboard Ultra courses.

These pages provide information that applies across courses. They are maintained in one place so updates can appear in every course that links to or embeds them.

## Pages

- `learning-in-blackboard.html` — finding course content, submitting work, checking progress, and getting Blackboard help

Additional pages are planned for technology tips, academic success and communication, and OCTC student support.

## What belongs in each Blackboard course

Faculty should provide their own welcome, contact information, syllabus, course materials, schedule, course navigation, policies, and first steps in Blackboard. The syllabus is the official source for course policies. Any quick-reference policy information in Start Here should match it.

## Maintaining these pages

- Keep content general enough to apply across OCTC courses.
- Do not add student information or course-specific or instructor-specific details.
- Check links and instructions before updating a page.
- Remember that changing a file name or this repository’s name may break links already placed in courses.
